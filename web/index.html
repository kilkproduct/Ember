    Cloud teachers
    
          
    These AIs write fuel on cloud GPUs / LPUs. Ember still trains on this phone. Each teacher has its own switch and usage window. When credits or the window run out, that switch flips off, you get a notification, and local firing continues.
    
        
    
        
    
          
          
        
    
        
    
          
          
          
        
    
        
    Keys never leave this device. Many providers block browser CORS — if a teacher errors, that is usually CORS or a missing free key, not Ember training.
